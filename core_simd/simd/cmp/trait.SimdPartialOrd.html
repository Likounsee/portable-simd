fn simd_in_range(self, min: Self, max: Self) -> Self::Mask
where Self: Copy + Sized, Self::Mask: BitAnd<Output = Self::Mask>,

🔬This is a nightly-only experimental API. (portable_simd)

Returns a mask indicating whether each lane is within the inclusive range from min to max.

A lane is true when it is greater than or equal to the corresponding lane in min and less than or equal to the corresponding lane in max. If a lane contains a floating-point NaN, its result is false.

This operation does not check that min is less than or equal to max; lanes with an inverted interval simply evaluate to false.

Source

fn simd_range<R: RangeBounds<Self>>(self, range: R) -> Self::Mask
where Self: Copy + Sized, Self::Mask: Copy + BitAnd<Output = Self::Mask> + BitOr<Output = Self::Mask> + Not<Output = Self::Mask>,

🔬This is a nightly-only experimental API. (portable_simd)

Tests whether each lane is contained in the corresponding range.

Included and excluded bounds are handled independently for every lane. Unbounded ends do not restrict the result. A fully unbounded range therefore matches every lane, including floating-point NaN values.

§Examples
let values = Simd::from_array([0, 1, 2, 3, 4]);
let min = Simd::splat(1);
let max = Simd::splat(3);
let inside: Mask<i32, 5> = values.simd_range(min..=max);
assert_eq!(inside.to_array(), [false, true, true, true, false]);
